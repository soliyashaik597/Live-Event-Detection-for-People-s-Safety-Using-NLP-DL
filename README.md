 # 🚨 Live Event Detection for People’s Safety using NLP & Deep Learning

An AI-based system that detects emergency situations from real-time voice and text inputs. The system converts speech to text, processes the data using NLP techniques, and uses deep learning models to classify events and determine their severity. It generates instant alerts to enable faster response.

## 🔹 Features
- Real-time detection from voice and text
- Speech-to-text conversion
- NLP preprocessing (tokenization, stopword removal, lemmatization)
- Event classification using deep learning
- Severity-based alert system

## 🔹 Tech Stack
- Python
- NLP (NLTK, spaCy)
- Deep Learning (LSTM, BERT)
- Speech-to-Text
- SQLite

## 🔹 Project Structure
- app.py
- audio_stream.py
- speech_to_text.py
- text_processor.py
- emergency_classifier.py
- decision_maker.py

## 🔹 How It Works
1. Capture input (voice/text)
2. Convert speech to text
3. Process using NLP
4. Classify event
5. Assign severity
6. Send alert
